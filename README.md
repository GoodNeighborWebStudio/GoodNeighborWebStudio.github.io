# Good Neighbor Web Studio

A static portfolio for a small-business web design studio. The site offers new websites and redesigns, quotes each project individually, and includes four fictional business concepts.

## Preview the website

Run `python3 -m http.server 8742 --bind 127.0.0.1 --directory docs` from the repository root, then open [the local preview](http://127.0.0.1:8742/).

## Publish to GitHub Pages

The intended repository is `GoodNeighborWebStudio/GoodNeighborWebStudio.github.io`. In Settings → Pages, select **Deploy from a branch**, then **main** and **/docs**.

## Receive quote requests

The contact form submits to FormSubmit, which sends requests to `yngyngjn.llc@gmail.com`. After publication, submit a test request through the live website and click the activation link in the confirmation email. Submit one more test to verify delivery. The contact section also has a direct email link.
