Good to know

Do I need experience?

Mat Foundations and Reformer Basics are designed for first-time visitors. Your instructor will walk through each movement.

Which class should I book first?

Start with Mat Foundations for a gentle introduction, or Reformer Basics if you’d like to try the equipment.

How large are the classes?

The sample schedule allows up to eight in a mat class and six on reformers.
